# 后台管理系统

## 项目简介

这是一个基于 Vue 3 + TypeScript + Arco Design Vue 的后台管理系统，用于管理课程、用户、订单等数据。

## 技术栈

- Vue 3 + Composition API
- TypeScript
- Arco Design Vue
- Vite
- Vue Router
- Pinia
- ECharts
- Sass

## 项目结构

```
src/
├── assets/          # 静态资源
├── components/      # 通用组件
├── layouts/         # 布局组件
├── router/          # 路由配置
├── views/           # 页面组件
│   ├── course/      # 课程管理
│   ├── user/        # 用户管理
│   ├── order/       # 订单管理
│   ├── statistics/  # 数据统计
│   └── system/      # 系统配置
├── main.ts          # 入口文件
└── App.vue          # 根组件
```

## 功能模块

- **课程管理**：课程列表、课程详情、课程编辑、章节管理、视频管理
- **用户管理**：用户列表、用户详情、用户推广树
- **订单管理**：订单列表、订单详情、退款管理
- **VIP会员管理**：VIP列表、VIP配置
- **分销管理**：分销商列表、分销配置、提现管理
- **数据统计**：数据概览、用户统计、销售统计、课程统计
- **系统管理**：基础配置、VIP配置、分销配置、短信配置、支付配置
